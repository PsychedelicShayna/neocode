# PR content

Retains the reported failure where a babysitting follow-up became a PR's title and body, its control, and the configured developer-instruction prefix case in `cases.json`. The fixture records the adversarial project instructions and the retired runner's exact launch option for later comparison. `grade.ts` and its offline cases still reject babysitting failures in generated PR content.

The Codex-only live runner is retired. NeoPi's disposable text-generation loadout disables project rules and context files and does not expose arbitrary configured developer instructions. Substituting that loadout would silently stop exercising the adversarial instructions and title-prefix contract, so no native replacement or successful live-eval coverage is claimed. A native instruction-injection seam is required before these saved fixtures can be run faithfully again.
